# Character.io

## Запуск

Из корня проекта:

```sh
cd server
go run .
```

Открой http://127.0.0.1:8080 и нажми «Войти». Go отдаёт страницу игры и принимает WebSocket-подключения на том же порту. Клиент автоматически подключается к `/ws`.

Если используешь Live Server, передай Go точный адрес страницы без пути через `-origin`, например `go run . -origin http://localhost:5500`. В адрес страницы в этом случае добавь параметр `?server=ws://127.0.0.1:8080/ws`.

## Где искать код

- `client/index.html` — экран игры и стили.
- `client/main.js` — ввод игрока, подключение, обработка снимков сервера и интерфейс.
- `client/prediction.js` — предсказание движения и сглаживание снимков.
- `client/scene.js` и `client/map-art.js` — персонажи, эффекты и оформление карты.
- `server/main.go` — запуск сервера, зоны захвата и точки появления. Укрытия и стены описаны в `server/map.go`.
- `server/websocket.go` — настройка WebSocket. Приём команд в `server/socket_session.go`, рассылка снимков в `server/socket_snapshots.go`.
- `server/messages/` — форматы сообщений WebSocket, по одному типу на файл.
- `server/arena.go` — очередь команд, игровой цикл и отправка снимков.
- `server/game/world.go` — состояние игроков, здоровье, скорость и перемещение.
- `server/game/combat.go` — урон, дальность, кулдауны и способности. Снаряды движутся в `projectile.go`.
- `server/game/control.go` и `server/game/bots.go` — захват точек и поведение ботов.

Клиент отправляет ввод по WebSocket. Арена применяет команды к игровому миру, затем рассылает снимки состояния. Клиент использует эти снимки для отрисовки.

## Тесты

Все тесты лежат в `server/tests/testdata`. Из папки `server` запусти:

```sh
go test -vet=off -overlay=tests/overlay.json ./...
go vet ./...
```

Первой командой Go временно подключает файлы тестов к их исходным пакетам. Так тесты продолжают проверять внутреннюю логику сервера. При добавлении нового тестового файла обнови `tests/overlay.json`. Отдельная команда `go vet` проверяет основной код, поскольку встроенный в `go test` анализатор не открывает виртуальные тестовые файлы.
